# Threat Actor Profiles
Esta seção reúne perfis de grupos e atores de ameaça analisados sob a perspectiva de Cyber Threat Intelligence (CTI).

Os perfis apresentam informações sobre identificação, motivação, alvos, histórico de atividade, TTPs, malware, infraestrutura e outros elementos relevantes para a compreensão de cada ameaça.

## Estrutura dos Profiles
Cada Threat Actor Profile pode conter:
- Identificação e aliases
- Motivação e objetivos
- Histórico e atividade conhecida
- Alvos e setores
- Táticas, Técnicas e Procedimentos (TTPs)
- Malware e ferramentas
- Infraestrutura
- Indicadores de Comprometimento (IOCs)
- Mapeamento MITRE ATT&CK
- Referências e fontes

---

## Metodologia
As análises são desenvolvidas utilizando conceitos e técnicas de:
- Cyber Threat Intelligence (CTI)
- Open Source Intelligence (OSINT)
- MITRE ATT&CK
- Threat Actor Analysis
- TTP Analysis
- IOC Analysis
- Infrastructure Analysis
- Malware Intelligence
